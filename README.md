# 🌟 Blackwood Mansion

*You can trust **NO ONE!!!**.*

**Blackwood Mansion** is our game developed for the **Brackeys Game Jam 2026.2**. 

- **Theme:** Trust No One
- **Genre:** Horror, Social Deduction
- **Status:** Finished

## 🎮 About the Game
In this game you are a visitor to a mansion where a murder took place, to not be the next victim you try to find the culprit amongst the residents of the mansion, finding hints gathered around the map and questioning each of the residents what were they up to. Will you be able to find who did it or die trying?

## ⌨️ How to Play
* **WASD:** Move around
* **E:** Interact/Select Action
* **Arrows:** Move through menus

## 🛠️ Made With
* **Engine:** Unity.
* **Art:** Aseprite.
* **Audio:** Audacity.
